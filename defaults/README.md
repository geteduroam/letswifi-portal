# Default configuration

This directory contains configuration files that are used as defaults.
Entries configured here are used as defaults if no configuration is set in `config/`.

It is not necessary to copy contents of this file.
Template configuration files can be found in `config-dist/`.

Do not modify files in this directory; these files are overwritten on upgrade.
If you want to make changes, anything set in `config/` will take priority over anything configured here.
